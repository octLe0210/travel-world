## 1. 项目概述

### 1.1 项目定位

世界之旅是一个面向全球旅行者的综合旅游信息平台，提供目的地探索、酒店预订、机票查询、租车服务、旅行攻略等一站式服务。网站以"杂志旅行风"为设计理念，融合 Monocle、Kinfolk 等高端旅行杂志的视觉美学。

### 1.2 核心特色

- **沉浸式启动页**：粒子星空 + 3D 地球 + GSAP 动画编排
- **杂志风排版**：Playfair Display 衬线标题 + 大地暖色调 + 呼吸感留白
- **全设备适配**：桌面/平板/手机三端响应式，侧边栏折叠 + 触摸手势
- **独立分类子页**：酒店/机票/租车各 20 条数据，含排序、筛选、分页
- **后台管理**：独立的 admin 后台，支持六大模块的增删改查

### 1.3 技术选型

| 技术 | 用途 | 选型理由 |
|------|------|---------|
| 纯 HTML/CSS/JS | 全站架构 | 零构建依赖，GitHub Pages 直接部署 |
| GSAP 3.12 | 动画引擎 | 高性能 timeline + ScrollTrigger，无 jQuery 依赖 |
| Playfair Display | 标题字体 | Google Fonts，衬线杂志感 |
| localStorage | 数据持久化 | 纯前端方案，无需后端数据库 |
| GitHub Pages | 部署平台 | 免费 HTTPS + 全球 CDN |

## 2. 界面设计（20 分）

### 2.1 设计理念

整体风格定位为"杂志旅行风"，参考高端旅行出版物（如 Monocle、Condé Nast Traveler）的排版美学——大图出血、衬线标题、暖色留白、精致网格。

【配图：首页完整截图】

### 2.2 色彩系统

| 色板角色 | 色值 | 用途 |
|---------|------|------|
| **主色（陶土棕）** | `#c67b4b` | 按钮、链接、高亮、选中态 |
| **主色深** | `#a05a35` | 按钮 hover、强调 |
| **页面底色** | `#f7f3ed` | 全局背景，暖纸白 |
| **卡片底色** | `#fffdf9` | 内容卡片，微暖白 |
| **侧边栏深色** | `#2c2416` | 侧边栏背景，深橡木 |
| **正文色** | `#3d3628` | 标题、正文文字 |
| **副文色** | `#8b7e6a` | 描述文字、辅助信息 |
| **边框色** | `#e8e0d5` | 卡片边框、分隔线 |
| **成功色** | `#27ae60` | 成功提示 |

**设计原则**：全局以大地暖色调替代传统冷灰/纯白，营造纸质阅读般的温润感。杂志感卡片不使用大圆角和重阴影，改用 `border: 1px solid #e8e0d5` + `border-radius: 4px` 的极细边框小幅圆角。

### 2.4 图标与图片

**图标**：使用 Emoji 作为场景图标（🏠🌍🏨✈️🚗📖📋），与旅行主题天然契合，无需额外加载图标库，减少网络请求。

**图片**：
- 全站图片来自 picsum.photos 占位图服务
- 所有 `<img>` 标签添加 `loading="lazy"` 原生懒加载
- 卡片图片包裹在 `.card-img-wrap` 容器中，统一 `height: 200-220px` + `object-fit: cover`
- hover 时 `transform: scale(1.04-1.07)` 轻微放大，增强交互感

**性能优化**：`<link rel="preconnect">` + `<link rel="dns-prefetch">` 预连接图片 CDN。

## 3. 响应式设计（30 分）

### 3.1 设备兼容性

网站支持以下设备：
- 桌面端（≥1024px）：完整侧边栏 + 三列卡片网格
- 平板端（768px-1023px）：两列网格 + 缩小标题
- 手机端（≤767px）：图标侧边栏 + 单列网格
- 小屏手机（≤360px）：进一步压缩间距

使用标准 HTML5 + CSS3，兼容 Chrome、Edge、Firefox、Safari 现代浏览器。

【配图：三种设备尺寸并排展示】

### 3.2 屏幕尺寸适应性

| 断点 | 侧边栏 | 网格列数 | 卡片图片 | 区块内边距 |
|------|--------|---------|---------|-----------|
| >1024px | 260px 完整 | 3 列 | 220px | 80px |
| 768-1023px | 260px 完整 | 2 列 | 200px | 60px 40px |
| ≤767px | 60px 图标 | 1 列 | 180px | 48px 24px |
| ≤360px | 60px 图标 | 1 列 | 160px | 32px 12px |

**自适应策略**：
- 使用 CSS Grid + `repeat(auto-fill, minmax())` 实现卡片自动换行
- 侧边栏通过 `@media` 断点切换宽度，菜单文字隐藏仅留图标
- 弹窗/搜索结果卡片从横向布局切换为纵向堆叠
- 表单从双列切换为单列
- 启动页地球、搜索框、统计数字随屏幕缩小等比缩放

【配图：各断点下的页面布局对比】

### 3.3 触摸交互优化

- **全局**：`touch-action: manipulation` 防止 300ms 点击延迟和双击缩放
- **卡片**：`:active` 伪类提供按压反馈（内阴影替代 shadow 浮动）
- **弹窗关闭**：支持下滑手势（`touchstart/touchend` 检测 ≥100px 垂直位移）
- **滚动容器**：`-webkit-overflow-scrolling: touch` + `overscroll-behavior: contain`
- **按钮**：GSAP `mousedown scale(0.96)` + `mouseup scale(1.04)` 提供按压弹力反馈

### 3.4 加载速度

| 优化项 | 实现方式 |
|--------|---------|
| DNS 预连接 | `<link rel="preconnect">` + `dns-prefetch` 对 picsum.photos 和 Google Fonts |
| 图片懒加载 | 全部 `<img loading="lazy">` |
| CSS/JS 内联 | 主站 CSS + JS 全部内联在 HTML 中，零外部文件请求 |
| 无框架依赖 | 不使用 React/Vue/jQuery，原生代码 |
| 缓存控制 | `Cache-Control: no-cache` meta 标签防止过期缓存 |
| 首屏体积 | 主站 HTML ~110KB，GSAP CDN 并行加载 |

**实际表现**：首屏加载 0.7s（GitHub Pages CDN），Lighthouse Performance 评分 90+。

### 4.2 交互体验

- **导航进度条**：全局 3px 橙色进度条，点击任何导航链接触发，GSAP 驱动
- **弹窗过渡**：入场 `back.out(1.4)` 弹性回弹，退场 `power2.in` 快速消失
- **卡片滚动入场**：GSAP ScrollTrigger 驱动，`toggleActions: 'play none none reverse'`
- **启动页入场序列**：GSAP Timeline 编排，地球弹出 → 标题淡入 → 数据滚动 → 按钮弹入
- **搜索框交互**：focus 时毛玻璃背景提亮 + 输入框宽度 GSAP 动画扩展
- **Toast 提示**：弹性入场 + 2.5s 后自动消失

### 4.3 错误处理

- **404 页面**：GitHub Pages 默认 404
- **空状态**：无数据时显示引导提示（"暂无预订记录" / "没有匹配的结果"）
- **表单验证**：实时错误提示，红色边框 + 错误信息
- **登录拦截**：未登录时预订/取消操作弹出"请先登录"Toast
- **网络错误**：图片加载失败由 `alt` 属性兜底

【配图：空状态 + 表单验证错误 + Toast 提示截图】

### 4.4 代码规范

- 语义化 HTML5 标签（`<aside>` `<nav>` `<main>` `<section>` `<footer>`）
- CSS 分区块注释（Reset → Sidebar → Splash → Cards → Overlays → Responsive）
- JS 分模块注释（Splash → Search → Data → Overlay → Booking → Login → Animations）
- 变量命名语义化（`showDetail` / `openHotelOverlay` / `triggerProgress`）
- 按钮添加 `aria-label` 无障碍标注（8 个返回按钮 + 2 个轮播箭头）
- 所有图片有 `alt` 属性
- 页面结构服务于表现分离——搜索框定位从内联 `style` 迁移到 CSS

### 6.3 动画系统架构

```
GSAP Timeline（启动页入场编排）
  ├── globeIn: scale(0→1) back.out(1.7)
  ├── titleIn: y(40→0) stagger
  ├── counters: innerText(0→target) snap
  └── buttonIn: scale(0.8→1) back.out(2)

GSAP ScrollTrigger（卡片滚动入场）
  ├── .card-grid children: y(40→0) stagger(0.08)
  └── .section-header: y(24→0)

GSAP overlay helpers
  ├── openOverlay(): fromTo → back.out(1.4)
  └── closeOverlay(): to → power2.in + onComplete
```
